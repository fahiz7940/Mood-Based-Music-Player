# 🎧 Mood-Based Music Player

A fun and creative music player built with **HTML**, **CSS**, and **JavaScript** where users can choose their current mood and enjoy a matching music track. 🎵

## 💡 Features

- 🎭 Select from four moods: Happy, Sad, Chill, and Energetic.
- 🎨 Dynamic background and theme based on mood.
- 🎧 Audio player with auto-play functionality.
- ✨ Smooth transitions and responsive design.
- 🔥 Built for learning, fun, and showcasing frontend skills.

## 🛠️ Tech Stack

- HTML5
- CSS3 (with custom styling)
- JavaScript (Vanilla)

## 📁 Project Structure

mood-music-player/ 
├── index.html # Main HTML file 
├── style.css # Styling for the UI 
├── script.js # Mood logic and audio handling 
└── asset/ # Folder with .mp3 files for each mood


## 🚀 How to Use

1. Clone or download the repository.
2. Make sure you have music files named:
   - `happy.mp3`
   - `sad.mp3`
   - `chill.mp3`
   - `energetic.mp3`
3. Place them inside the `/assets` folder.
4. Open `index.html` in your browser and enjoy!
